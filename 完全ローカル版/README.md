# 🫣 ひょっこりアニメーションアプリ (完全ローカル版)

インターネット接続が一切不要（完全オフライン・単一ファイル）で動作する、ひょっこりアニメーション用のWebアプリケーションです。OBS Studioなどの配信ソフトのブラウザソースや、デスクトップ上の演出としてもそのままご利用いただけます。

## 🌟 主な特徴

- **完全ローカル・オフライン対応**
  - 外部CDNや外部サーバーへの依存をすべて排除。`index.html` 1ファイルだけで動作するため、インターネットが繋がらない環境でも完全に動作します。
- **かわいいデフォルトのうさぎキャラクター**
  - 初期状態として、オフラインでも表示可能な愛らしい「うさぎのイラスト（SVG）」を内蔵しています。
- **画面端からの「ひょっこり」アニメーション**
  - **上から出現:** 180度回転して *逆立ち* で顔を出します。
  - **左から出現:** 時計回りに傾いて顔を出します。
  - **右から出現:** 反時計回りに傾いて顔を出します。
  - **下から出現:** 自然な角度で顔を出します。
- **背景完全透過**
  - OBSなどのオーバーレイとして利用しやすい完全透過デザイン。
- **インタラクティブな反応**
  - 出現中のキャラクターをタップ／クリックすると、驚いた音（Web Audio APIによる自動合成）と共にサッと引っ込みます。
- **充実のカスタム設定パネル (⚙️)**
  - 画面右上の薄い歯車ボタンから、以下の設定をリアルタイムに変更・調整できます：
    - **キャラの変更:** お好きな画像（PNG/SVG/JPEG）や動画（透過WebMなど）をアップロード可能。
    - **キャラクターサイズ:** 80px〜350pxで調整可能。
    - **出現頻度:** 最大出現間隔（2〜30秒）の調整。
    - **滞在時間:** 基準となる滞在時間の調整。
    - **ひょっこり具合（深さ）＆揺らぎ幅:** 画面に出る深さや毎回ランダムに変わる揺らぎ幅の調整。
    - **効果音(SE):** 有効/無効の切り替え。
- **設定の自動保存 (`localStorage`)**
  - アップロードした画像や調整した設定はブラウザに自動保存されます。

## 🚀 使い方

1. `index.html` ファイルをブラウザ（Google Chrome, Edge, Safari など）で直接ダブルクリックして開きます。
2. （OBSなどの場合）OBSの「ブラウザソース」にこの `index.html`（またはローカルファイルのパス）を指定して読み込ませます。
3. 画面右上の **⚙️（歯車アイコン）** にマウスオーバーまたはタップすると設定モーダルが開き、キャラクターの変更や各種タイミングの調整が行えます。

## 🛠️ 技術構成

- **HTML5 / CSS3 / JavaScript (ES6+)** - `index.html` 単一ファイル構成
- **Web Audio API** - 外部音源ファイル不要の効果音合成
- **SVG Data URI** - ネット接続不要の組み込みキャラクターグラフィック
