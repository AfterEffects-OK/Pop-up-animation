# 🫣 ひょっこりアニメーションアプリ (Peek-a-boo Animation)

画面の四辺からランダムなタイミングでキャラクターが「ひょっこり」顔を出して引っ込む、Webベースのインタラクティブ・アニメーションアプリです。

## 🌟 主な機能と特徴

- **画面端からの「ひょっこり」アニメーション**
  - **上から出現:** 180度回転して**逆立ち**で顔を出します。
  - **左から出現:** 時計回り（プラス方向）に傾いて顔を出します。
  - **右から出現:** 反時計回り（マイナス方向）に傾いて顔を出します。
  - **下から出現:** ランダムな角度で自然に顔を出します。
- **背景完全透過**
  - 背景や余計なUIが排除された透過デザインのため、他のウィンドウや配信画面のオーバーレイ（OBS等）としても最適です。
- **インタラクティブ反応**
  - 出現したキャラクターをタップ／クリックすると、驚いた音と共に素早くサッと引っ込みます。
- **カスタム設定パネル (⚙️)**
  - 画面右上の薄い歯車ボタンをクリックすると、設定モーダルが開きます。
  - **画像の変更:** お好きなPNG/SVG/JPEG画像（透過画像推奨）をアップロード可能。
  - **出現頻度:** 1秒〜30秒の間で最大出現間隔をスライダーで変更可能。
  - **キャラサイズ:** 80px〜350pxまでリアルタイムにサイズ変更可能。
  - **効果音（SE）:** Web Audio APIによる合成音声で、音量の調整およびON/OFF切り替えに対応。
- **設定の自動保存 (`localStorage`)**
  - アップロードした画像や調整したサイズ・頻度などの設定はブラウザに自動保存され、リロードしてもそのまま復元されます。

---

## 🚀 使い方

1. `index.html` をブラウザで直接開きます（特別なサーバー環境は不要です）。
2. ランダムな時間（1〜30秒）と場所からキャラクターがひょっこり顔を出します。
3. 画面右上の **⚙️（歯車アイコン）** を押すと設定画面が開き、キャラクター画像の変更やサイズ・出現頻度の調整ができます。

---

## 🛠️ 技術構成

- **HTML5 / CSS3 / JavaScript (ES6+)** - 単一ファイル (`index.html`) で動作
- **Tailwind CSS** (CDN) - 設定ダイアログのデザイン
- **Web Audio API** - 外部音源ファイル不要の効果音自動合成
